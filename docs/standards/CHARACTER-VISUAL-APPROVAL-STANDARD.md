# Our World Games — Character Visual Approval Standard v1

**Purpose:** define when a written character spec becomes approved game art.

A character is never visually approved from prompt text alone.

This standard applies to portraits, sprites, 2.5D/3D models, animation tests, marketing art, and future Our World avatars.

---

## 1. Approval states

- **SPEC DRAFT** — written identity is incomplete.
- **SPEC READY FOR ART** — enough canon exists to create a trustworthy visual test.
- **ART TEST** — at least one real visual implementation exists.
- **REVISION REQUIRED** — visual output breaks canon or studio standards.
- **VISUALLY APPROVED** — passes portrait, movement/gameplay-scale, and cast-comparison review.

---

## 2. Five gates

A character must pass all five.

### Gate A — Age

- reads as the intended child age
- no mini-adult anatomy
- no toddler/chibi drift unless the whole approved art direction intentionally uses that proportion language
- no adult makeup/glam styling
- clothing fits a child in the setting

### Gate B — Identity

- face is distinct from other named characters
- skin depth/undertone remains consistent
- body/height relationship matches canon
- wardrobe/signature object supports identity but does not replace it
- character still reads correctly in a neutral outfit test if needed

### Gate C — Black hair

Must pass `BLACK-HAIR-DIGITAL-STANDARD.md`.

Especially check:
- construction/parting
- silhouette
- accessories
- movement behavior
- small-screen readability
- continuity across poses/angles

### Gate D — Gameplay read

At approximate in-game size:
- silhouette can be distinguished quickly
- character does not depend on tiny facial details to be recognized
- important props/accessories are visible enough or intentionally omitted
- color is not the only identity cue
- motion/idle behavior supports recognition

### Gate E — Cast coherence

In a lineup:
- children look like they belong to one art universe
- no reused generic face with swapped hair
- range exists in skin, face, hair, height/build, clothes, posture, and energy
- boys/girls read as intended where relevant without caricature
- nobody is visually reduced to a stereotype

---

## 3. Required review views

Minimum for a named V1 character:

1. portrait/3-quarter view
2. full-body standing view
3. approximate gameplay-scale view
4. full cast lineup

Add side/back views when hair, backpack, long strands, silhouette, or game camera requires them.

For animated builds, add:
5. short idle/run/turn test

---

## 4. Contemporary-kid check

The goal is not to chase every micro-trend. It is to avoid obviously dated or generic styling.

For contemporary games, references should be refreshed before production art and should check:
- sneaker silhouettes
- pants/jeans/jogger proportions
- outerwear/layering
- graphic tee/hoodie/varsity usage
- backpack/accessory scale
- current age-appropriate hair styling

Current 2026 reference research for the first cast notes relaxed silhouettes, wider-leg pants, statement sneakers, coordinated sets and graphic tees among Gen Alpha fashion signals; use this as context, not a mandatory uniform.

Do not make every Black child streetwear-coded. A kid's interests and personality should drive styling.

---

## 5. Reference ethics

Use references to understand:
- construction
- proportions
- movement
- fabric/hair behavior
- styling vocabulary

Do not reproduce a real child as a game character without explicit rights/consent.
Do not save identifying private child material in the repo.
Use public/editorial/product references cautiously and only as study material unless the license permits direct asset use.

Dove Code My Crown and OSAHL are educational/reference sources for textured hair representation. Their assets remain subject to their own current terms and licenses.

---

## 6. AI-art review rule

Prompt accuracy is not output accuracy.

Even if a prompt specifies the right details, reject an output that shows:
- age drift
- face drift
- skin-tone drift
- incorrect hair construction
- floating/fused accessories
- repeated face templates
- adult body/glam styling
- impossible clothing/hand/hair intersections
- franchise-like imitation
- cultural stereotype shorthand

A generated image is a candidate asset, not canon, until reviewed.

---

## 7. Cast-lineup questions

Review the full cast without names visible.

Can a reviewer identify each child from:
- face
- hair silhouette
- height/build
- wardrobe shape
- signature object
- posture/energy

Then hide or neutralize one cue at a time.

If removing hair makes two kids become the same person, the faces/body language are under-designed.
If removing outfit color makes them indistinguishable, silhouettes are under-designed.
If every girl is braids and every boy is a fade, the cast lacks range.

---

## 8. Approval checklist

- [ ] Intended age reads correctly.
- [ ] Face is distinct from every other named character.
- [ ] Skin depth and undertone match canon.
- [ ] Body/height relation matches canon.
- [ ] Hair passes Black Hair Digital Standard.
- [ ] Clothing feels age-appropriate and character-specific.
- [ ] Silhouette reads at gameplay scale.
- [ ] Motion supports identity.
- [ ] Boy/girl presentation reads as intended where relevant without stereotype shortcuts.
- [ ] Character fits the shared art world.
- [ ] Character is still identifiable in the cast lineup.
- [ ] No visual element copies an existing franchise character.

Only after all required checks pass may the status become **VISUALLY APPROVED**.
