## 7. Reference board — lawful + small

Gather references for construction, not identity copying.

Required categories:
1. hairstyle construction/parting
2. age-appropriate clothing silhouette
3. footwear/accessory scale if important
4. motion behavior if hair/props need special handling

For every reference, record:
- source URL or source note
- what we are studying from it
- what we are **not** copying

Do not store private child photos in the repo.
Do not copy one real child's face/body/outfit wholesale.
Do not upload OSAHL source models into AI training workflows.

---

## 8. Art test brief

Create:

### A. Portrait test
- neutral 3/4 view
- full face readable
- hair construction visible
- waist-up or full-body depending on game

### B. Full-body test
- neutral standing pose
- child proportions obvious
- entire outfit + shoes visible

### C. Gameplay-scale test
- actual approximate in-game size
- silhouette still distinct
- hairstyle still reads without caricature
- signature object visible only if gameplay needs it

### D. Side/back test
Required whenever hair construction, backpack, long braids/twists/locs, or silhouette depends on unseen angles.

---

## 9. AI-assisted concept prompt block

If using generative image tools, include all of the following in the prompt:

- original fictional Black child
- exact age
- childlike proportions and face
- skin depth + undertone
- specific facial structure
- exact hairstyle construction, length, accessories, silhouette, movement expectation
- exact clothing silhouette
- game art style
- no adult makeup/glamour/sexualization
- no generic reused face
- no franchise imitation

### Negative/rejection guidance

Reject/regenerate if:
- child looks substantially older/younger than intended
- hair roots/parts are nonsensical
- beads/accessories float or fuse
- puffs become perfect hard balls
- braids/twists/locs behave like straight loose hair
- face drifts toward another cast member
- outfit becomes adult nightlife/influencer styling
- boy/girl readability relies only on lashes/pink/blue

---

## 10. Cast comparison gate

Place this character beside the whole cast.

Ask:
- Can I name them without labels?
- Is the face distinct?
- Is the silhouette distinct?
- Is the hair distinct **without carrying the entire identity**?
- Do they look like they belong in the same world and age band?
- Does anyone look like a duplicate with a palette swap?

If any answer fails, revise before build approval.
