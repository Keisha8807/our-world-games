# Game Concept Card — TEMPLATE (v3.1)

**Target length: ~2 pages for an ordinary game.** If it's turning into a full GDD, cut or move reusable rules into the Studio Bible/standards.
Everything about representation, safety, privacy, accessibility, and tech baseline lives in
`STUDIO-DESIGN-BIBLE.md` and `standards/` — don't rewrite those rules here.

**Layers:** Studio Design Bible + shared standards (once) → **this card** (every game) → one Genre Module (`modules/`) → Builder Handoff (generated from the approved card).
