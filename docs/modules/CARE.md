# Module — CARE / NURTURE
*For pet-care, vet, babysitting, plant-tending style games.*

### C1. Patient / dependent states
The finite list of states (hungry, hurt, scared, itchy, sleepy…) and how each is shown with an icon + animation.

### C2. Diagnosis
How the kid figures out what's wrong: look, listen, poke, thermometer? Keep it observational, not text.

### C3. Treatment actions
Verb list (bandage, feed, brush, cuddle, medicine). Which action fixes which state. Mini-interaction per action (drag, tap-hold, rhythm)?

### C4. Recovery & payoff
What a healed patient does (happy dance, thank-you, goes home). This is the emotional payoff — spend juice here.

### C5. Care loop & pacing
How many patients per round, do they arrive in waves, is there a queue? Pressure should feel like *busy*, not *failing*.

### C6. Fail state
What happens if you're slow or wrong? (Patient gets grumpier, never dies. Always recoverable.)

### C7. Collection
Pet Journal / patient cards / stickers. How many collectibles in V1 and how earned.

### C8. Randomization per round
Species, ailment combos, arrival order, personalities — list what re-rolls.
