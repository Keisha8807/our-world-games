# Module — RHYTHM
*For beat-timing / jump-rope / dance / clapping games.*

### R1. Beat source
BPM range for V1, whether music is original, and how the beat is *visually* shown (ropes, rings, bouncing marker) so it works with sound off.

### R2. Input
One input (tap/space) or two? Define exactly what one press does.

### R3. Timing windows
Perfect / good / miss windows in ms. Kid-generous by default (perfect ≈ ±80ms, good ≈ ±160ms). Tune in playtest.

### R4. Combo & multiplier
Combo rules, when it breaks, what it visibly does (crowd, sparkles, rope on fire — no fire).

### R5. Speed progression
How tempo ramps inside a round and across rounds. Cap for V1.

### R6. Pattern generation
Hand-authored patterns (count for V1) vs. procedural. Trick moves (crossover, double-under) if any.

### R7. Fail state
Trip on the rope = funny stumble + immediate re-entry. No "game over" wall on first miss.

### R8. Score & chase
Score formula, local best, and the "one more try" hook (what's *almost* reachable next time).

### R9. Randomization per round
Track, pattern order, cameo turners, crowd — list what re-rolls.
