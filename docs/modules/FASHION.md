# Module — FASHION
*For dress-up / styling / identity-expression games.*

### F1. Theme generation
Where prompts come from (list of N themes for V1), how one is chosen, and how it's shown (icon + 2 words).

### F2. Wardrobe categories
Slots (hair, top, bottom, shoes, accessory, nails, etc.) and item counts per slot for V1. Hair is a *category*, with texture-true options (Bible §3) — not a hat slot.

### F3. Style requirements
What makes an outfit "fit the theme"? Explicit tags per item; a theme = required tags + bonus tags.

### F4. Creative freedom
How much of the score is rule-following vs. personal flair? There must be more than one "right" answer.

### F5. Scoring layers
Theme match / color harmony / signature piece / speed. Show the breakdown visually, never as a red X.

### F6. Judging & feedback
Who judges (crowd meter, runway lights, friends' reactions)? Feedback must be warm and specific.

### F7. Unlocks & collection
What's earned per round, how it's displayed (Closet), and how many unlockables exist in V1.

### F8. Pressure
Timer per round? Rounds per session? Fail state (a "meh" score is still a cute outfit).

### F9. Randomization per round
Theme, available items, bonus tag, judge mood — list what re-rolls.
