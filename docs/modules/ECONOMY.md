# Module — ECONOMY
*For grow / sell / upgrade / tycoon-lite games.*

### E1. Earn
The primary earn action and its base yield. One currency in V1.

### E2. Spend
What money buys (seeds, stock, upgrades). Countable shop list for V1.

### E3. Produce
Time-to-grow / time-to-make. Real-time timers or turn-based days? (Prefer short, in-session cycles; no offline timers in V1.)

### E4. Sell
Who buys (customers walking by, market stall), price rules, any demand variation.

### E5. Upgrade
The 3–5 upgrades in V1 and what each visibly changes.

### E6. Progression balance
Target: first upgrade within 2 minutes, all V1 upgrades within ~15 minutes. Write the numbers.

### E7. Fail / setback
Weather, a bug, a sold-out day — setbacks are small, funny, and never wipe progress.

### E8. Session & return
What ends a session (day ends) and what pulls the kid back tomorrow (something is *about* to be ready).

### E9. Randomization
Customers, prices, weather, events — list what varies.
