# Module — DEDUCTION
*For mystery / whodunit / social-deduction-flavored single-player games.*

Fill each item with V1 numbers. Rule of thumb: the **game does the logic, the kid gets the aha.**

### D1. Roles
Hidden roles per round, how many of each, and how they're assigned. (V1 target: 2 story roles max.)

### D2. Hidden information
What does the player *not* know at the start? What is the exact thing they're trying to learn?

### D3. Clue logic
How clues narrow the suspect pool. State the generator rule explicitly (e.g. clue 1 fits 3/4, clues 1+2 fit 2/4, all 3 fit only the culprit). No single clue may solve it. Visual/icon clues preferred over text.

### D4. Red herrings
Who acts guilty but isn't, why, and how the player clears them. Red herrings must be *funny*, never mean.

### D5. Behavioral evidence
How each role *moves/acts* differently so observation is a real skill (dash, glance, hide, flee, idle).

### D6. Solution validation
How accusing works: when it's allowed, what a correct/wrong accuse does, and how the game shows *why* (the missed clue) so a wrong answer teaches instead of frustrates.

### D7. Case board
The player's memory aid. What's on it, what's auto-tracked, what's a tap away. Pictures, not notes.

### D8. Pressure
Timer? Chaser? Both? Define the fail state and make sure it's recoverable within the same round.

### D9. Randomization per round
List exactly what re-rolls (culprit, herring, secret, clue placement, premise) — this *is* the replay hook.
